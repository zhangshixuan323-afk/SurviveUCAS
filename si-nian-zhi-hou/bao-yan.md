# 保研

先叠甲：本文仅记录本人27届保研经历及思考，所有内容均有时效性，仅供参考


## 保研形势分析

1. 随着coding agent迅速发展，计算机、人工智能类的科研门槛降低，推免时几乎所有人都有科研经历，大部分人都有论文。

   > 这将带来两个方面影响：一是内卷竞争进一步加大，大学期间提早进组科研、发表论文似乎已经成了刚需；二是高水平科研更为稀缺，虽然人人有科研经历，但是大部分是AI搬砖、或者没有很好insight的杂活（据笔者一位审稿人师兄说，26年的NeurIPS就有很多AI水文，所以简历上的“在投”的含金量都有待商榷），这表明这也意味着，**选组、选题和投稿平台的选择，比盲目数量堆叠重要得多**。

2. 人工智能发展迅速，更多人拥入AI领域保研深造，跨保人数激增，比如笔者夏令营认识了很多数学、物理、金融专业进行跨保并拿到offer的，ai/cs保研人数激增，尤其是在特定方向如大模型、具身智能赛道。

3. 目前保研有几种名额：学硕、专硕、直博、联培直博。可以预见的是学硕名额将不断缩减，以后趋势大概是奔着就业的读专硕，想要深造的读直博。

这就说明，保研到好学校的难度相较以往难度剧增，只有提前规划、早做打算，才能把握住机会。



## 保研那些事

### 保外校

1. 一定要关注各个学校夏令营时间点，尤其是中关村学院、上海创智等，早在5月份就开营了，在此推荐一个网站：[2026计算机专业夏令营、预推免保研通知汇总 | 保研信息平台](https://baoyanxinxi.cn/2026jsjby/)

2. 区分强弱com院校，如果要去弱com院校一定要提前联系导师，可能连营都入不了。不过这只是入营要求，如果要去好组，最好都提前套磁。理想情况：4、5月份套磁，历经3个月左右有一定产出。当然如果要去清北强组最好是大二就联系，保证一年的实习。

   > 在此列举一下，清北、中科大、上交复旦直博都是弱com。尤其是上海的学校和实验室并不是很认可国科大的title，如果要投递最好把简历刷好看点。就身边人例子，如果没有特别突出的科研经历，rank 10投上海院校是被拒的

3. 多方面准备，除了计算机专业知识，数学、算法机试、英语都要准备，这方面准备建议多刷几个经验帖。

在此梳理一下几个夏令营的风格：

（1）中关村学院、上海AILAB、上海创智：大差不差，都是组队黑客松（给定赛题，规定时间内做出结果并汇报面试，但说白了就是agent大战），有的可能有额外笔试机试。

> 避坑要点：一定要抱到靠谱队友 + API 额度充够！小组最终结果直接挂钩个人评价，如果遇到摆烂队友真就只能自求多福了。

（2）中科大cs：弱com，如果不联系老师入营完全随缘，国科大rank 5未入营，但是湖大rank 20入营，比较迷。

（3）上交cs：大海营，硕士机试+面试，博士只有面试。面试考察数学+科研，而且必有英语介绍项目。优营好拿，但是导师名额不好拿。

（4）浙大cs：不同组用不同的考察方式，大部分要求线上面试通过后，线下或者线上做为期一个月的实习（同等情况线下优先录取），需要权衡和其他夏令营冲突

（5）人大高瓴：面试基本拉不开分差，主要注意笔试方面：cs专业学生建议多复习线代、机器学习、概率论方面知识，也是考察重点；最后大题必是算法、数学二选一（满分75，这占了15），数学偏概率论，算法从近几年来看都是leetcode hot 100原题，建议全刷一遍。还有csp 300可以笔试加分

### 保本校

cs类学生可以保叉院，计算所，自动化所，软件所等，出路很多，而且拿到本校offer一般都没有问题，唯独风险在于：

1. rank太低，没有入营（叉院这方面ban掉的人比较多；计算所可以霸面）
2. 所里导师名额很少，比如计算所一个老师基本是一博一硕，建议提前和老师沟通好名额分配。注意有的老师可能除了所里的名额，还有国科大校本部的名额，可以多加了解

总体考核情况如下：

（1）叉院：为期3天，考核仅有面试，而且对国科大本科生很包容、问的问题都很友好。

> 不过要注意前几次有集中活动要签到，没签上也要提前请假，否则会被取消资格

（2）自动化所：国科大学生有专门的提前批，考核15分钟面试，纯简历面，无英语数学考察

（3）计算所：所里开始会组织集中综合素质考核，据说是考cs专业四大件，不过霸面的同学甚至可以不用参加；后续会有笔试和面试，笔试考察数学、算法、逻辑思维（逻辑题基本不参考）分三张卷子，说是会筛人不过没有看到有本校生被笔试筛了的；面试看组，一般是目标组里的老师集中面你一个，风格因组而异，普遍涵盖英语 + 科研 + 数学基础。）

总体而言保本校，只要rank不太低基本都有希望拿到offer，大多数没有成功推免的人都是拿了offer但是没有老师要（这个在自动化所中特别常见）。这就要在大二大三的科研实习中通过提前进组实习，和老师沟通来弥补了。

此外，一定要确切沟通好名额分配，身边有的同学导师签了双选表却把学生鸽了，也有同学明明沟通好了但是导师跳槽去其他方了，一旦遇上这种突发状况会非常被动，只能海投或被迫考研。

希望大家都能顺利推免！
