# 序：虽千万人，吾兴高采烈往矣。

亲爱的读者，你好。我们是一群来自国科大的本科生。如果你也是中国科学院大学的一员，我们同你一样爱着这个校园，正因如此，我们无意伤害母校的声誉，更不是要声讨或者表示愤怒，我们纯粹的幻想着，能用自己的笔，给学生们写下一些路。我想，这是真正的回馈母校的方式。虽千万人，吾兴高采烈往矣。

国科大致力于成为培养科学家的摇篮，这一理想是崇高的，现实却是遗憾的。在这个摇篮里，我们竟然真的成了一个个婴儿，等待着大人的安排，被分配去各个“前沿”，并为之庆幸。他们却无法回答：世界的前沿到底在哪里？学校的外面是什么？此时此刻的世界发生着什么？其他的孩子在哪儿，在做什么？最重要的是，离开布置好的一切，我想要什么？

井底之蛙总是苍白的，比较谁的五子棋更胜一筹，在真正的现实里不堪一击。我们终将离开这座围城，城外的世界是什么模样？彼时彼刻，我们的智慧，能承受住那些真正的、来自现实世界的考验吗？

这是一个提供思考的平台，希望帮助大家质疑一些我们习以为常的假设，强调一些没有被关注过的思考，竭力向大家展示一些校园之外的真实。这本册子不是《国科大成功学》，不教人走上成功暴利的道路，更不教人考前速成、保研捷径。我衷心的希望，在阅读之后，大家能对四周坚定的轨道产生一丝动摇，并且开始想象在校园之外另一个更加广阔的世界，并且有勇气、有智慧发现并挑战那些比上课更为重要的追求。
